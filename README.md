# 寻风 (XunFeng) - 本地信息收集工具

寻风是一款功能强大的跨平台信息收集工具，专为安全研究人员和渗透测试人员设计。它能够高速、精准地扫描全盘文件，发现潜在的敏感信息、危险配置和高价值进程，并提供灵活的配置选项以适应不同环境。

## 功能特性

- **跨平台支持**: 可在 Windows, Linux, macOS (Intel & Apple Silicon) 上运行。
- **扫描**:
    - **敏感内容**: 基于强大的正则表达式库，扫描文件内容中的密码、密钥、API Token、数据库连接字符串等。
    - **敏感文件**: 识别因文件名或后缀本身就具有高风险的文件（如 `id_rsa`, `.db`）。
    - **危险权限**: 发现系统中“全局可写”的目录，这些是常见的提权风险点。
    - **高价值进程**: 识别正在运行的数据库、Web服务器、OA/ERP系统、DevOps工具等关键进程。
- **性能**: 默认使用多线程并发扫描，充分利用CPU资源。
- **精度**:
    - 内置丰富的排除规则，智能跳过系统目录、开发依赖和缓存文件，大幅减少误报。
    - 进程识别基于完整的命令行，而非简单的进程名，结果更精准。
- **Bypass (Stealth Mode)**: 支持扫描节流，通过设置延迟来模拟正常I/O行为，能轻微的规避一下EDR/HIDS的检测。

## 使用

### 1. 运行扫描

该工具通过命令行参数进行配置。

**基础用法:**

```bash
# 在 macOS / Linux 上
./XunFeng

# 在 Windows 上
.\XunFeng.exe
```
默认情况下，这将使用所有CPU核心进行全速扫描，并将结果输出到 `result.txt`。

**参数说明:**

- `-o <文件名>`: 指定输出报告的文件名。
  - 示例: `./XunFeng -o my_scan_report.log`
- `-t <数量>`: 设置并发扫描的线程数。默认为系统的CPU核心数。
  - 示例: `./XunFeng -t 4` (使用4个线程)
- `-s <毫秒>`: 开启延迟模式，设置每次文件操作的延迟时间（毫秒）。
  - 示例: `./XunFeng -s 50` (每次操作延迟50毫秒，推荐用于规避检测)

**组合示例:**

```bash
# 使用8个线程，以100毫秒的延迟扫描，并将结果保存到 report.txt
./XunFeng -t 8 -s 100 -o report.txt
```

### 3. 查看报告

扫描结束后（或被中断后），所有发现都会被整理并输出到您指定的文件中（默认为 `result.txt`）。

1.  **敏感信息 (Content Hits)**
2.  **敏感文件 (Sensitive Files)**
3.  **目录权限 (Directory Permissions)**
4.  **运行中进程 (Running Processes)**
5.  **扫描摘要 (Summary)**
